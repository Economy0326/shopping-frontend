1. 메인 페이지
-> 쇼핑몰 이름
-> 상품별 카테고리
-> 로그인
-> 검색창
-> 메인 사진
-> 할인 상품(이벤트 상품), 신상품 (생략 가능)
-> 현재 순위 (생략 가능)
-> 카카오톡 채널 연결 (생략 가능)
-> 회사 소개, C/S 하는법(시간+전화번호), 은행 계좌번호, 교환/반품 주소, 100개 이하 일 시 우체국 이용
-> 홈으로/회사 소개/ 이용약관/ 개인정보보호/ 이용안내/ 고객센터/ 자주 묻는 질문 카테고리만들기
-> 인스타그램 홍보 (생략 가능)
-> 룩북칸

2. 로그인 페이지 (로그인, 비밀번호 모두 만들기 + 보안 공부)
-> 바로 전 페이지로 돌아가기
-> 메인으로 돌아가기
-> 회원가입 하는법 설명 (복잡하면 생략가능)
-> 네이버/카카오로 회원가입하기
-> 기존 회원 OR 비회원 클릭 가능한 태그
-> 아이디/ 비밀번호 인풋 만들기
-> 아이디/ 비밀번호 찾기 파트 만들기

2-2. 회원가입 페이지

3. 장바구니 페이지 (마이페이지)
-> 국내배송상품, 해외배송상품 파트 따로 나누기
-> (주문내역) 이미지, 상품정보, 판매가, 수량, 적립금, 배송구분, 배송비, 합계, 선택(주문하기, 관심상품등록, 삭제)
-> 총 상품금액 + 총 배송비 => 최종 금액 알려주는 파트
-> 결제하기 버튼
-> 전체상품주문/선택상품주문/쇼핑계속하기 파트 나누기
-> 이용안내 ( 장바구니 이용하는법, 무이자할부 이용하는법) (생략 가능)

4. 결제 페이지
-> 장바구니 (주문내역) 그대로 가져오기
-> (배송 정보) 배송지 선택[회원 정보와 동일, 새로운 배송지], 받으시는 분, 주소, 휴대전화, 이메일, 배송메세지
-> 결제 예정금액, 할인 금액, 총 결제 금액
-> 결제 수단 (무통장입금, 신용카드, 계좌이체, 가상계좌)
-> 무통장입금 -> 입금자명, 입금은행, 현금영수증
-> 신용카드 -> 카드선택, 할부기간, 결제안내, 결제 대행 동의
-> 계좌이체 -> 예금주명, 현금영수증
-> 무이자 할부 이용안내
-> 이용 안내(세금계산서 발행, 부가가치세법 변경에 따른 신용카드매출전표, 현금영수증)

5. 상품 상세설명 페이지
-> 판매가격, 컬러, 사이즈 선택할 수 있게
-> 상품에 대한 간단한 설명 (소재, 모델 스펙, 상품 특징)
-> 추가구성상품
-> 바로구매하기, 장바구니 넣기
-> 상품에 대한 확대 사진
-> 상품에 대한 자세한 설명과 함께 다른 방향에서의 사진들 추가 삽입
-> 사이즈 정보(M, L 일 때 -> 어깨 가슴 소매 등등)
-> 착용 정보(계절감, 신축성, 무게감, 비침 등등) 
-> 상세 정보(소재, 세탁방법, 색상, 담당자 번호) 
-> 주의 사항(환불 불가 사유)
-> 사용 후기(리뷰)
-> Q&A

6. 고객센터 페이지
